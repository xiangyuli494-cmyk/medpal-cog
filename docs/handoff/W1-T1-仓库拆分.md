## 1 这次做了什么

1. 把 `agent/` 的历史用 `git subtree split` 抽成独立仓 `medpal-cog`，**10 个提交的作者与时间原样保留**，内容展平到仓根。
2. 修掉展平后失效的路径：`skeleton.py`、`tests/test_trace_schema.py`、`tools/check_evaluator.py`、`tools/probe_llm.py`，删根 `__init__.py`。
3. 补齐工程基线：`README`（评委向）、`CONTRIBUTING`、`CODEOWNERS`（新路径）、`pyproject`、`requirements-dev`、`.gitattributes`、三条 job 的 CI、`deploy/`（Dockerfile + compose）、`docs/adr/ADR-001`、`docs/migration.md`、`docs/judge-guide.md`。
4. 新增 `tools/selfcheck.py`：一条命令跑种子库 / pytest / 评测 / 骨架 / 契约校验。
5. 顺手修了个真问题：`store.add_triple` 的 `triple_id` 原来是 `uuid4`，每次 seed 都重写快照；改成 `sha1(head|rel|tail)` 前 8 位，快照现在可复现（同输入同 `manifest_hash`）。
