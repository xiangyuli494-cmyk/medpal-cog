## 4 已知问题与坑

| 现象 | 原因 | 绕法 / 待办 |

| `--from v0.9 --to v0.9` 全是 0 | 仓库里现在只有 `ontology_v0.9.jsonl` 一份快照 | 真实 v1.0 要等 W2 的 `onto_commit` 落快照；本期用夹具 `tests/fixtures/ontology_v1.0_demo.jsonl` 演示三态，**它不是真版本** |
