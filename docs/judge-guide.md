## 常见提问与答法

1. 为什么不只做 RAG？我们需要结构化实体关系、版本差分及逐步可回放的引用；当前跨文档业务验收仍是明确缺口。
2. 为什么自研 MCP？十工具统一了资产、图查询和版本/trace 的输入输出，便于把平台行为落成可核查记录。
3. 为什么用 SQLite 而不用 Neo4j？当前图很小，单机数据库便于复现和版本快照，新的存储系统不会解决证据缺失。
4. 离线分数可信吗？只作为合成样本回归；修复空证据假满分后证据召回为 0.476，不代表临床正确率。
5. 团队如何协作？T1 负责接入、集成、证据与材料；T2 负责本体、对齐和版本化；T3 负责数据、评测、可视化与交付。
