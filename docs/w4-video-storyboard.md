## 1 录屏规格（开拍前定死）

| 项 | 设定 |
| --- | --- |
| 分辨率 | 1920×1080；浏览器缩放 100%，控制台/终端字号调大到可读 |
| 时长 | 3:30–4:30，硬上限 5 分钟 |
| 音轨 | 旁白后期配（不在现场念）；背景无键盘声/环境噪音 |
| 字幕 | 逐句上屏，白字黑边；术语首次出现给全称：MCP / Skill / ICD-10 / trace |
| 编码 | mp4（H.264 + AAC）；单文件，不切合集 |
| 环境 | 干净 clone + 新 venv；`NO_PROXY=127.0.0.1,localhost`；`PYTHONIOENCODING=utf-8` |
| 兜底 | 现场网络/投影不可控时，本视频就是兜底演示（judge-guide 材料清单第 6 条） |
