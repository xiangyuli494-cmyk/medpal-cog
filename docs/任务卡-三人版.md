## 三人共用的三条纪律

1. **一次 PR 只做一件事**：≤400 行，标题 `type(scope): 中文动宾`，贴证据；分支名见计划 §9.1。
2. **先红再绿**：先写会失败的测试或评测条目，PR 里贴红灯。
3. **骨架坏了全组停手**：`python tools/selfcheck.py` 不绿期间只允许修它。
