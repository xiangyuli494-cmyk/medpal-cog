## 5 裁剪清单（做 / 不做 / 降级）

**保留做厚**

1. 10 个 MCP 工具 + 3 个 Skill 包（评委直接看得见的能力面）
2. 可进化三行为：本体会长、决策会变、能力会沉——**现场演，不靠 PPT 讲**
3. 决策链溯源：每一步都必须有 `anchor_id`
4. 一条命令起重（`tools/selfcheck.py`）+ 离线评测报告

**降级**

| 原计划 | 降级为 | 理由 |
| --- | --- | --- |
| Streamlit 台账页 | 生成静态 HTML（脚本 `tools/build_pages.py`） | 少一个进程、少一类现场故障 |
| 评测 50 条 | 30 条（20 必做 + 10 加分） | 20 条足够出六项指标，50 条会把 W3 吃光 |
| 图像视觉模型 | 已标注 `image_report` 卡（20 张） | 训练不产出可演示增量 |
| 自建向量库/Neo4j | Nexent 知识库 + SQLite | 存储不是这题的评分点 |

**不做（写进边界声明，答辩主动讲）**

- 不覆盖全科室、不做处方与用药建议（只到「科室 + 检查」）
- 不做多租户 / 权限体系 / 移动端
- 不做独立前端工程与构建链
- 不接真实医院数据，全部公开可开源数据
