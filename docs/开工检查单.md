## 1. 克隆并确认拿到的是 main

```bash
git clone https://github.com/xiangyuli494-cmyk/medpal-cog.git
cd medpal-cog
git log --oneline -1        # 应看到 main 最新一条
git ls-files | wc -l        # 216
```

仓库自带 61 份资产样例、20 条评测题、37 条本体三元组，**不需要额外找数据**。

## 2. 装依赖

```bash
python -m pip install -r requirements.txt -r requirements-dev.txt
```

PDF 解析用到 PyMuPDF（`pip install pymupdf`）是可选项：不装时 PDF 用例自动 skip，其它测试照跑。

## 3. 跑绿（这一步过了才算「环境好了」）

```bash
python tools/selfcheck.py --fast
```

期望输出：`全绿（4 步）。可以提 PR 了。` 完整版去掉 `--fast`，会多跑评测与骨架。

单独跑也行：

```bash
python -m pytest tests -q          # 49 passed（装 PyMuPDF 时 0 skip）
python eval/run_eval.py            # 20 条，六项 100%
python tools/acceptance.py         # PASS 16 / FAIL 0 / MANUAL 3
```

> 这几条命令会自己建库、自己灌样例，**不要**手动 `git add mcp-server/data/medpal.db`。

## 5. 提交规矩（三句话）

1. 从 main 开分支，名字 `feat/{模块}-{动宾}` 或 `fix/{模块}-{动宾}`，例：`feat/mcp-pdf-modality`。
2. 一次 PR 一件事、≤400 行；标题 `type(scope): 中文动宾`；贴证据（贴命令输出，不写「已测试」）。
3. 开 PR 后等 CI 三绿（lint / test / pipeline）→ 找 T1 approve → T1 合并。**自己不能合自己的 PR**。

细节见 `docs/git-flow.md`；红线见 `CONTRIBUTING.md` §3。
